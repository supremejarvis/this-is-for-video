## 1. કાર્યકારી સારાંશ (Executive Summary)

Apollo Engineering પ્લેટફોર્મ એ ભારતની પ્રથમ સોલાર ક્લીનિંગ હાર્ડવેર (SS304 શેડોલેસ સ્પ્રિંકલર્સ અને ડ્રેઇન ક્લિપ્સ) બનાવતી ઔદ્યોગિક મેન્યુફેક્ચરિંગ સિસ્ટમ છે. હાલની સિસ્ટમનું Next.js ફ્રન્ટએન્ડ અને Python FastAPI બેકએન્ડ ખૂબ જ શક્તિશાળી આર્કિટેક્ચર પર આધારિત છે, પરંતુ ડીપ ટેકનિકલ ઓડિટ દરમિયાન નીચે મુજબના મુખ્ય મુદ્દાઓ સામે આવ્યા છે:

| ક્ષેત્ર (Domain) | હાલની સ્થિતિ (Current State) | મુખ્ય સમસ્યા (Key Issues) | જરૂરી એક્શન (Action Needed) |
| :--- | :--- | :--- | :--- |
| **Admin Panel Codebase** | એક જ ફાઇલમાં 4,295 લાઇનનો મોનોલિથિક કોડ (`SuperAdminDashboard.tsx`) | હાર્ડકોડેડ એડમિન પાસવર્ડ/TOTP બેકડોર, લોકલ સ્ટેટ અને બેકએન્ડ ડીબી વચ્ચે ડેટા ડિસિંક | સિક્યોરિટી ફિક્સ (P0), મોડ્યુલર સબ-પેજીસમાં વિભાજન |
| **Admin Navigation & UX** | ટેબ્સ URL ક્વેરી પેરામ્સ સાથે જોડાયેલી છે | મોટા ડેટાસેટ વખતે આખું ડેશબોર્ડ ફરી રી-રેન્ડર થાય છે | નેસ્ટેડ રૂટ્સ (`/admin/products`, `/admin/orders`, વગેરે) |
| **Storefront Performance** | Lighthouse સ્કોર: **35/100** (ખૂબ ધીમું) | **LCP 14.7s**, **TBT 2,150ms**, વિશાળ JS બંડલ અને અનઓપ્ટિમાઇઝ્ડ ઈમેજીસ | Dynamic Imports, Image Caching, Bundle Splitting |
| **Monetary & Tax Accuracy** | ક્લાયન્ટ-સાઇડ ફ્લોટિંગ પોઇન્ટ કેલ્ક્યુલેશન | GSTR-1 એક્સેલ અને સ્ક્રીન પર પૈસાના રાઉન્ડિંગમાં અમુક જગ્યાએ `JS Float` વપરાય છે | AGENTS.md § 3 મુજબ 100% Python `Decimal` નો ઉપયોગ |
| **B2C vs B2B Isolation** | બેનર અને ટોગલ હાજર છે | અમુક સમયે B2B ટાયર્ડ પ્રાઈસ B2C વપરાશકર્તાને મૂંઝવણમાં મૂકી શકે છે | સખત સેસન આધારિત કેટલોગ આઇસોલેશન |

## 2. ભાગ ૧: ADMIN PANEL ઓડિટ (એડમિન પોર્ટલ)

### ૨.૧ કયા સેક્શન્સ ક્યાં હોવા જોઈએ અને તેમાં શું હોવું જોઈએ?

હાલમાં એડમિન પેનલ ૭ મુખ્ય સ્તંભો (Pillars) માં વહેંચાયેલી છે. દરેક સેક્શનનું આદર્શ સ્થાન અને તેમાં શું હોવું જોઈએ તેની વિગત:

#### ૧. પ્રોડક્ટ્સ અને વેરિઅન્ટ કેટલોગ (`/admin/products`)

- **ક્યાં હોવું જોઈએ:** મેઈન નેવિગેશનમાં પહેલું ટેબ.
- **તેમાં શું હોવું જોઈએ:**
  1. **PostgreSQL ડાયરેક્ટ સિંક ટેબલ:** ASIN, SKU, પ્રોડક્ટ ટાઇટલ, કેટેગરી, HSN કોડ (73269099 / 84248990), લાઇવ સ્ટોક સ્ટેટસ.
  2. **વેરિઅન્ટ મેનેજમેન્ટ:** પેનલ ફ્રેમ જાડાઈ (30mm, 35mm, 40mm, Universal Fit) અને પેક સાઈઝ (50, 100, 500 pcs) મેનેજમેન્ટ.
  3. **ડ્યુઅલ પ્રાઈસિંગ એડિટર:**
     - **B2C રિટેલ પ્રાઈસ:** MRP અને સેલિંગ પ્રાઈસ (18% GST સાથે).
     - **B2B ટાયર્ડ હોલસેલ પ્રાઈસિંગ:** સ્લેબ વાઈઝ રેટ્સ (દા.ત. <1000 pcs @ ₹17, 1000+ @ ₹15, 2500+ @ ₹10).
  4. **ઇન્સ્ટન્ટ સ્ટોક અપડેટર:** ટેબલમાં જ ઇનલાઇન ઇનપુટ સાથે ક્વિક બટન્સ (`-10`, `+10`, `+50 Master Pack`).
  5. **ફેક્ટરી રી-ઓર્ડર શીટ (PO Generator):** ૧૦૦ યુનિટથી ઓછો સ્ટોક હોય ત્યારે ૧-ક્લિકમાં પરચેઝ ઓર્ડર શીટ બનાવવી.
  6. **ઓડિટ લોગ ડ્રોઅર:** કયા એડમિને ક્યારે ભાવ કે સ્ટોક બદલ્યો તેની હિસ્ટ્રી.

#### ૨. ઓર્ડર્સ અને ડિસ્પેચ કન્સોલ (`/admin/orders`)

- **ક્યાં હોવું જોઈએ:** બીજું ટેબ, જેમાં નીચે મુજબ ૪ સબ-સેક્શન હોવા જોઈએ:
  1. **ડિસ્પેચ પાઇપલાઇન (`/admin/orders?view=dispatch`):**
     - જે ઓર્ડર્સ પેક કરવાના બાકી છે તેનું લિસ્ટ.
     - ૧-ક્લિકમાં India Post Speed Post Article Number બારકોડ જનરેટ કરવો.
     - CEPT સ્પીડ પોસ્ટ બલ્ક મેનિફેસ્ટ (Bulk Manifest JSON & Printable PDF).
     - થર્મલ 4x6" ઇન્ડસ્ટ્રીયલ શિપિંગ લેબલ પ્રિન્ટિંગ (કાઠવાડા જીઆઇડીસી હબ 382430 સાથે).
  2. **ફાઈનલ ઓર્ડર્સ (`/admin/orders?view=orders`):**
     - તમામ પૂર્ણ થયેલા અને ચાલુ ઓર્ડર્સનું ફિલ્ટરેબલ લિસ્ટ (PENDING, PAID, SHIPPED, DELIVERED, CANCELLED).
     - કસ્ટમર ડિટેલ્સ, પેમેન્ટ મોડ (UPI, Razorpay, COD), કુરિયર ટ્રેકિંગ લિંક.
     - ઓથોરિટેટિવ ટેક્સ ઇન્વોઇસ પ્રિન્ટ/ડાઉનલોડ.
  3. **પેન્ડિંગ કાર્ટ્સ - એબેન્ડન્ડ કાર્ટ રિકવરી (`/admin/orders?view=pending_carts`):**
     - જે ગ્રાહકો કાર્ટમાં માલ મૂકીને ચેકઆઉટ કર્યા વગર જતા રહ્યા હોય તેમનું લિસ્ટ.
     - ગ્રાહકનું નામ, ફોન નંબર, કાર્ટ વેલ્યુ અને ૧-ક્લિક WhatsApp Recovery બટન (ઓટોમેટેડ મેસેજ: `SOLAR5` કુપન સાથે 5% વધારાનું ડિસ્કાઉન્ટ).
  4. **રિટર્ન્સ અને રિપ્લેસમેન્ટ્સ (`/admin/orders?view=returns`):**
     - ગ્રાહકે ખોટી સાઈઝ મંગાવી હોય તેનો વર્નિયર કેલિપર/સ્કેલ ફોટો વેરિફિકેશન ડેસ્ક.
     - રિટર્ન કુરિયર ચાર્જ (₹45 + 18% GST) મંજૂર/નામંજૂર કરવાનું વર્કફ્લો.

#### ૩. પેમેન્ટ્સ અને રીકોન્સિલિએશન (`/admin/payments`)

- **ક્યાં હોવું જોઈએ:** ત્રીજું ટેબ.
- **તેમાં શું હોવું જોઈએ:**
  1. **Razorpay Gateway Settlement:** Razorpay Order ID, Payment ID અને બેંક UTR નંબરનું ઓટોમેટેડ મિલાન.
  2. **ડ્યુઅલ સ્ટેજ વેરિફિકેશન લોગ્સ:** ક્લાયન્ટ તરફથી આવેલો રિસ્પોન્સ અને સર્વર-ટુ-સર્વર વેબહૂક (HMAC-SHA256) વેરિફિકેશન સ્ટેટસ.
  3. **ડાયરેક્ટ UPI QR અપ્રૂવલ ડેસ્ક:** જે ગ્રાહકોએ ડાયરેક્ટ UPI QR સ્કેન કરીને પેમેન્ટ કર્યું હોય તેમના UTR સ્ક્રીનશોટ જોઈને ઓર્ડર મેન્યુઅલી `PAID` કરવાનો ડેસ્ક.
  4. **COD સરચાર્જ એકાઉન્ટિંગ:** COD પર લાગેલા 2.5% સરચાર્જ અને પોસ્ટ ઓફિસ તરફથી આવતા કેશ કલેક્શનનું ટ્રેકિંગ.

#### ૪. ગ્રાહકો અને B2B GST વેરિફિકેશન ડેસ્ક (`/admin/customers`)

- **ક્યાં હોવું જોઈએ:** ચોથું ટેબ.
- **તેમાં શું હોવું જોઈએ:**
  1. **ગ્રાહક ડિરેક્ટરી:** B2C ગ્રાહકો અને B2B કોન્ટ્રાક્ટર્સનું અલગ લિસ્ટ.
  2. **GSTIN વેરિફિકેશન મોડ્યુલ:** ગ્રાહકનો GST નંબર સાચો છે કે નહીં, કંપનીનું નામ અને 18% ITC ક્લેમ માટે યોગ્ય છે કે નહીં તેની ચકાસણી.
  3. **કોન્ટ્રાક્ટર ઇન્ક્વાયરી ડેસ્ક:** વેબસાઇટ પરથી આવેલી B2B સોલાર પ્રોજેક્ટ ઇન્ક્વાયરીઓ, સાઇટ ક્ષમતા (kW/MW) અને ૧-ક્લિક કોલ/વોટ્સએપ લીડ મેનેજમેન્ટ.

#### ૫. પ્રમોશન્સ અને કુપન્સ (`/admin/coupons`)

    - કેટલા ડ્રેઇન ક્લિપ્સ જોઈશે (૨ પ્રતિ પેનલ).

    - પાઇપ ફિટિંગ્સ, એન્ડ કેપ્સ અને પંપ રિક્વાયરમેન્ટ.
  - ૧-ક્લિકમાં આખી કીટ કાર્ટમાં ઉમેરવાનું બટન.

#### ૬. ઓથોરિટેટિવ કાર્ટ ડ્રોઅર (`CartDrawer.tsx`)

- **સ્થાન:** રાઇટ સાઇડ સ્લાઇડ-ઓવર પેનલ.
- **તેમાં શું હોવું જોઈએ:**
  - પિનકોડ ડિલિવરી ચેકર: ગ્રાહક પિનકોડ નાખે એટલે કાઠવાડા હબ (382430) થી સ્પીડ પોસ્ટ કુરિયર ચાર્જ લાઈવ ગણાય.
  - ૧૫-મિનિટ પ્રાઈસ & સ્ટોક લોક ટાઈમર: સર્વર સાથે સિંક થયેલું કાઉન્ટડાઉન.
  - પારદર્શક GST બ્રેકડાઉન: પ્રોડક્ટ ટેક્સેબલ રકમ + 18% પ્રોડક્ટ GST + કુરિયર ચાર્જ + 18% કુરિયર GST.
  - COD લિમિટ ચેક: B2C માં ₹10,000 થી વધુના ઓર્ડર પર COD ડિસેબલ કરીને ફક્ત પ્રીપેડ રાખવું.

#### ૭. ચેકઆઉટ મોડલ અને ઓર્ડર કન્ફર્મેશન (`CheckoutModal.tsx`)

- **સ્થાન:** `/checkout`.
- **તેમાં શું હોવું જોઈએ:**
  - સ્ટેપ ૧: ડિલિવરી એડ્રેસ અને બિલિંગ એડ્રેસ (B2B હોય તો GSTIN ઇનપુટ).

  - COD માટે MSG91 એન્ટિ-ફ્રોડ 4-ડિજિટલ OTP વેરિફિકેશન (ફેક ઓર્ડર્સ રોકવા માટે).
